01

领域定位：CAD 生成到底在生成什么？

What is being generated, and why it is hard

CAD 的本质不是"一个 3D 形状"，而是一段带参数、带约束、带历史的建模过程。 工程师先画草图、再拉伸、再切除、再倒角——每一步都携带着参数与设计意图。 因此 CAD 生成任务可统一表述为：把设计意图（文本 / 图像 / 点云 / 工程图）映射为一段可被 CAD 内核执行并验证的程序。

核心矛盾：视觉相似 ≠ 工业可用。 现有评测常用归一化后的 Chamfer Distance 与 IoU，对毫米级数值偏差并不敏感——两个尺寸存在细微差异的模型，IoU 可能都高达 0.96。 但在工业语境下，0.7cm 被"四舍五入"成 0.67cm，就足以让零件报废。这正是"AI + 工业"故事讲不下去的共同原因。

◈两大核心数据表达

① 建模历史树（参数树 / CSG 树）：记录"怎么建出来的"，天然可编辑、可改参数，但序列长、长程依赖强。
② B-Rep 边界表示：用 NURBS 精确描述面 / 边 / 顶点及其拓扑关系，是制造与仿真的标准格式，但拓扑不规则稀疏，生成难度大。

关键洞察：现代特征化 CAD 系统中，参数化建模与 B-Rep 本质是交织的——高级参数操作（如倒角、倒圆）必须显式选择 B-Rep 几何原语，而 B-Rep 本身又由参数操作导出。

◈五大技术难点

设计历史与长程依赖 · 几何约束求解 · 拓扑正确性（无自交 / 水密 / 非流形）· 设计意图保持 · 真实工业数据稀缺。

为什么难：CAD 编译器不可微，无法直接对生成的序列施加几何有效性梯度；渲染过程又是"多对一"的，多个参数序列可渲染出同一外观。
02

核心设定体系：四个维度

Data Representation · Conditioning · Paradigm · Supervision

调研发现，几乎所有 CAD 生成工作都可以用四个维度的"设定"来精确刻画。理解这四维，就理解了整个领域的设计空间。

A数据表示设定

CAD 用什么"语言"表达？命令序列、代码 DSL、B-Rep、CSG 树、指针增强序列、潜码本——表示决定了能力上限。

取舍：命令序列 token 短但无实体选择能力；代码精度高但 token 长约 4 倍、推理慢 4.7–6.6 秒。

B输入条件设定

无条件 / 文本 / 图像 / 点云 / 工程图 / 多模态 / UI 操作序列。条件越丰富，越贴近真实设计场景。

趋势：从单模态走向多模态统一（CAD-MLLM、VisCAD、cadrille 三模态合一）。

C生成范式设定

自回归 Transformer / 扩散模型 / 状态空间模型 / LLM 微调 + 强化学习 / 程序综合与 Agent 工具调用。

演进：纯 SFT → SFT + RL（视觉反馈、几何奖励），让模型学会"渲染出来好不好看、能不能执行"。

D训练与评测设定

序列信号（teacher forcing）/ 视觉信号（渲染反馈 RL）/ 几何信号（Chamfer、有效性）；评测从形状级走向参数级。

最新：Pointer-CAD v2 提出 Vertex / Edge / Face Accuracy 三级参数精度指标 + RMR@3 可修复模型率，且不做归一化。

设定 C · 生成范式：五条技术路线

Autoregressive · Diffusion · LLM+RL · SSM · Program Synthesis

①自回归 Transformer

把 CAD 命令序列当作语言，用 Transformer 逐 token 预测下一个操作。 典型架构是"编码器 + 解码器"两段式：编码器把序列压成 latent，解码器自回归还原。

代表：DeepCAD（ICCV 2021）、SkexGen、CAD-Llama（CVPR 2025）、CADTrans、SolidGen、AutoBrep、Pointer-CAD。
动机：序列结构清晰、训练稳定，是最早跑通的范式。

②扩散模型

用去噪扩散过程生成 CAD 表示。B-Rep 方向尤其流行，因为可以设计结构化潜空间来保证拓扑有效性。

代表：BrepGen（多阶段：面→边→顶点）、BrepDiff（单阶段 + 掩码 UV 网格）、DTGBrepGen、GenCAD（潜扩散）、Draw Step by Step。
动机：扩散擅长建模复杂分布；单阶段比多阶段更易编辑。

③LLM 微调 + 强化学习

先 SFT 建立基础生成能力，再用 RL 对齐"渲染效果"或"几何精度"。 奖励可来自视觉偏好、Chamfer 距离、代码可执行性。

代表：CADFusion（序列学习 ↔ 视觉反馈交替）、CAD-Coder（GRPO + 几何/格式奖励）、ReCAD、ToolCAD、cadrille（在线 RL）、ICML 2026（SFT→RL）。
动机：仅序列监督忽略全局外观，渲染又是多对一映射。

④状态空间模型

用 Mamba 等 SSM 架构替代注意力，以线性复杂度处理超长 CAD 命令序列。

代表：Mamba-CAD（AAAI 2025）。
动机：复杂工业模型的命令序列极长，Transformer 注意力成本过高。

⑤程序综合 / Agent 工具调用

把 CAD 生成视为程序合成问题：用约束求解（SAT）逆向恢复 CSG 树； 或让 LLM Agent 调用 CAD 工具链，形成"规划—执行—反思"闭环。

代表：InverseCSG（SAT 程序综合）、ToolCAD、Zero-to-CAD（agentic 合成百万级数据）、text-to-cad（开源 Agent 技能库，15K stars）。
动机：几何内核可执行可验证，天然适合"生成—验证—修正"循环。

⑥多阶段 vs 单阶段

B-Rep 生成的两条路线：多阶段逐元素生成（面→边→顶点）保证拓扑有效，但级联依赖僵硬； 单阶段一次性生成，速度快 3–21 倍且支持编辑。

代表：BrepGen（多阶段）vs BrepDiff（单阶段）。
动机：多阶段早期决策被后期固化，难以灵活编辑与解释。

设定 D · 训练信号与评测基准

Supervision signals · Datasets · Metrics

训练信号：三种监督来源

S序列信号

用 ground-truth 参数序列做 teacher forcing。提供序列结构与参数操作的直接监督，但只强调局部 token 连续性，难捕捉全局外观。

V视觉信号

把生成的序列渲染出来，用视觉偏好做 RL 奖励。弥补"渲染多对一"问题，让模型学到"看起来对不对"。

G几何信号

Chamfer Distance、有效性、拓扑约束、代码可执行性。直接对齐"能不能用"，但 CAD 内核不可微，需通过 RL 或后处理施加。

评测指标：从形状级走向参数级

◐形状级指标

Chamfer Distance (CD) IoU COV MMD JSD R coverage D JSD

问题：通常在归一化后计算，对毫米级数值偏差不敏感，会掩盖尺寸误差。

◐命令级指标

F1（命令 / 参数准确率）SegE（分割误差，衡量拓扑正确性）

用途：衡量生成序列与真值序列的操作级一致性。

◐拓扑有效性指标

IR（无效率）SIR（自交率）DangEL（悬边长度）FluxEE（密封质量）valid_ratio

用途：判断生成结果能否成为合法实体，是工业可用的硬门槛。

◐B-Rep 结构指标

Surface F1 Edge F1 Vertex F1 Topology F1

用途：ECCV 2026 CAD Challenge 采用，用 OCCT 内核网格化 + 点云采样 + 匈牙利匹配评分。

★参数级指标（2026 新增，标志性演进）

Vertex Accuracy：预测顶点与 GT 最近点欧氏距离在容差内才算匹配。
Edge Accuracy：不仅端点定位正确，底层几何参数（圆弧圆心与半径、圆法向等）也须在容差内对齐。
Face Accuracy：所有边界边被正确识别，且原始体类型（平面/圆柱/圆锥/球/圆环）与 GT 一致。
RMR@3：错误面不超过 3 个的模型占比，衡量真实 CAD 工作流中的可用性。

关键设定：容差为 GT 包围盒最小边长的千分之一，且所有模型在原始位置与尺度下评测、不做归一化——迫使模型真正理解文本指令中的度量尺度。

代表性论文卡片：方法 + Motivation

30 works, method and motivation in one card each

01DeepCAD

ICCV 2021命令序列自回归

方法：Transformer 自编码器 + 自回归生成。命令集 {Line, Arc, Circle, EOS, SOL, Ext}，每个命令由离散类型与连续参数组成，参数经量化后嵌入。

Motivation：把 CAD 建模当作一种语言——生成可编辑的参数化序列，而非只能看的 mesh。这是该方向的奠基工作。

02SketchGraphs

ACM TOG 2022约束图数据集

方法：1500 万真实 2D 草图，表示为几何约束图（节点=图元，边=约束），附开源数据处理管线。

Motivation：2D 草图是 3D 参数化建模的基础，但缺乏真实手绘数据；自动约束与草图补全可显著提升设计效率。

03InverseCSG

SIGGRAPH 2019CSG 树程序综合

方法：把 mesh 逆向为 CSG 树，形式化为程序综合问题。先用 RANSAC + 图割做鲁棒基元检测（解连续搜索），再用 SAT 求解器 Sketch 解纯离散搜索。

Motivation：大量遗留模型已丢失原始设计过程，只剩网格或扫描数据；恢复紧凑的 CSG 表示才能重新编辑与制造。

04SkexGen

2022命令序列解耦编码

方法：解耦编码器分别编码拓扑、几何与构造信息，再自回归生成草图-拉伸序列。

Motivation：CAD 序列中拓扑、几何、构造三类信息纠缠，解耦后能提升生成的多样性、合理性与可控性。

05SolidGen

TMLR 2023B-Rep自回归

方法：自回归直接合成 B-Rep 结构，逐元素生成顶点、边、面。

Motivation：绕过命令序列这一中间层，直接生成制造就绪的 B-Rep 表示。

06CAD-MLLM

2024多模态LLM 对齐

方法：用 LLM 对齐文本 / 图像 / 点云等多模态特征与 CAD 命令序列的向量化表示，实现多模态条件生成。

Motivation：真实设计输入本就是多模态的；这是首个统一多模态条件的 CAD 生成系统。

07Text2CAD

NeurIPS 2024文本→CAD

方法：Transformer 框架 + 多层次文本标注（从粗略到精细描述），把自然语言映射为参数化 CAD 命令序列。

Motivation：自然语言是最自然的设计意图表达方式；让非专家也能通过描述生成 CAD 模型。

08BrepGen

SIGGRAPH / TOG 2024B-Rep扩散·多阶段

方法：扩散模型 + 结构化潜几何，多阶段依次生成面、边、顶点。

Motivation：B-Rep 拓扑高度不规则稀疏，分阶段生成可保证拓扑有效性与结构合理性。

09CADFusion

2025LLM视觉反馈 RL

方法：以 LLM 为骨干，交替进行序列学习（SL）与视觉反馈（VF）两个训练阶段：SL 用真值序列保证逻辑连贯，VF 奖励渲染后视觉更优的序列。

Motivation：CAD 天然多模态（参数序列 + 渲染外观），且渲染是"多对一"映射——只用序列监督会忽略全局外观，且过度偏向训练集中出现过的序列。

10GenCAD

2024 / 2025图像→CAD潜扩散

方法：四步——① 自回归 Transformer 学 CAD 命令序列 latent；② 对比学习对齐 CAD latent 与图像 latent；③ 条件潜扩散按图像 latent 生成 CAD latent；④ 预训练 decoder 解码回参数化序列，交给几何内核生成实体。

Motivation：让 AI 生成"建模过程链"而非表面形状——生成的是 line / arc / extrude 等操作及参数，改孔径、改倒角都能联动。

11CADCrafter

2025无约束图像→CAD

方法：三阶段训练。阶段 1 用 Transformer 自编码器编码 CAD 命令序列（{SOL, L, A, R} + 拉伸 E）；阶段 2 用几何条件编码器提取深度图与表面法线（DINO 预训练）；阶段 3 对齐生成。

Motivation：逆向工程依赖昂贵 3D 传感器；图像到 3D 生成表面粗糙、无编辑性；真实图像-CAD 对稀缺、单视图信息不完整、CAD 编译器不可微。

12CAD-Llama

CVPR 2025LLMSEM 格式

方法：利用 LLM 生成参数化 3D CAD 模型，采用 Sketch-and-Extrude Modeling（SEM）格式表示 CAD 对象。

Motivation：把 LLM 的语言能力直接迁移到参数化 CAD 生成，复用预训练知识。

13Mamba-CAD

AAAI 2025状态空间模型

方法：用状态空间模型（Mamba）做 3D CAD 生成建模，替代注意力机制。

Motivation：CAD 命令序列长，Transformer 注意力复杂度高；SSM 以线性复杂度建模长程依赖。

14BrepDiff

SIGGRAPH 2025单阶段扩散

方法：单阶段扩散直接生成 B-Rep。核心是"带掩码的 UV 网格表示"（面参数域离散为 N×N 网格 + 可见性掩码）+ 异步噪声调度（坐标 [0,1000]，掩码 [0,500]）+ 纯几何后处理恢复实体。

Motivation：多阶段流程级联依赖僵硬，早期决策被后期固化，难以灵活编辑与解释；单阶段让所有面共同优化，支持补全、合并、插值等编辑操作，且速度快 3–21 倍。

15CADTrans

2025码树正则化码本

方法：把模型分解为实体、轮廓、环三种原语，用向量量化对抗网络训练三个正则化离散码本，构建自上而下的码树，再用 Transformer 自回归生成。

Motivation：VQ 方法存在码本坍缩问题；正则化策略让更多信息通过码本瓶颈，学到更丰富的数据表示，同时支持用户编辑与可控生成。

16CAD-Tokenizer

2025模态专属 token

方法：用序列化 VQ-VAE 做原语级池化，把草图-拉伸对压缩为多个离散 token；训练 adapter 对齐预训练词表与骨干嵌入；引入有限状态自动机（FSA）约束解码保证语法合法。

Motivation：标准 LLM tokenizer 会把 CAD 序列切成自然语言词片（如 "[extru] [-sion]"），打散操作与数值参数，导致注意力层关注标点而非有意义的原语，无法建模几何结构依赖。

17cadrille

2025VLM在线 RL

方法：多模态 CAD 重建模型，同时处理点云、图像、文本三种输入。两阶段：大规模程序化生成数据上 SFT，再做在线 RL。

Motivation：借鉴 LLM 训练范式；单模态方法各有短板，统一三模态可提升鲁棒性。SFT 模型在 DeepCAD 基准上同时超越三种单模态方法。

18Pointer-CAD v1

CVPR 2026指针序列

方法：三类 token——Label（操作语义）、Value（数值参数）、Pointer（直接引用 B-Rep 面/边）。B-Rep 编码为无向面邻接图，GNN 聚合特征；Qwen2.5 + LoRA 微调，双预测头（token 分类 + 128 维指针嵌入余弦匹配）。多步自回归，每步以文本 + 前序 B-Rep 为条件。

Motivation：命令序列法无法做实体选择（倒角/倒圆需要选边选面），且连续参数量化误差破坏拓扑；代码法 token 长（平均 424.75）、推理慢（4.72–6.61s）。指针机制让 0.5B 模型超越 7B 的 CADmium。

19Pointer-CAD v2

ECCV 2026Plan-Then-Construct

方法：先让模型输出结构化设计计划（Plan），再据此构造 CAD。基于 Qwen3 标注 OmniCAD-Plan（20.2 万）/ Plan+（20.9 万）计划级监督数据。提出三级几何精度指标（Vertex / Edge / Face Accuracy）+ RMR@3。

Motivation：现有方法与评测协议只强调视觉相似度，忽视精确几何参数与度量尺度。2-bit 量化下 0.7cm 只能被"四舍五入"成 0.67cm，工业上足以让零件报废；而 CD / IoU 归一化后对此不敏感。7B 模型 RMR@3 达 95.23%。

20ReCAD

方法：用视觉语言模型 + 强化学习增强参数化 CAD 模型生成。

Motivation：纯监督学习难以保证几何准确性，RL 可对齐最终几何质量。

21Seek-CAD

ICLR 2026自精炼

方法：自精炼生成建模，通过 DeepSeek 做局部推理修正生成结果。

Motivation：一次性生成难以保证质量，自精炼让模型迭代改进自身输出。

方法：LLM 生成可执行 CadQuery 脚本，并引入"基于文本的查询机制"——LLM 用自然语言指定几何选择，由 B-Rep grounding transformer 定位到目标原语。SFT 建立基础能力，RL 提升泛化。

Motivation：参数化建模与 B-Rep 在现代特征化 CAD 系统中本质交织（高级参数操作需显式选择 B-Rep 原语，B-Rep 又由参数操作导出），但现有方法分为两个割裂的阵营，这一范式鸿沟限制了复杂工业产品设计的 AI 化。

23HiFi-BRep

2026高保真 B-Rep

方法：面向工业级零件图纸的高保真 B-Rep 生成，在 DeepCAD 与 ABC 两个公认基准上评测。

Motivation：让 AI 画出"真正能用"的工业零件图纸，而非仅视觉合理的形状。

24Zero-to-CAD

2026Agentic 合成

方法：无真实数据条件下，用 agentic 合成引擎在百万级规模生成可解释 CAD 程序；ViT-LLaMA 架构从多视图图像端到端生成可运行 CAD 代码。全流程开源（合成引擎、评估工具链、100K 数据集、微调代码与 checkpoint）。

Motivation：AI for CAD 长期受困于数据——现有构造历史数据规模小（<10k）、覆盖操作单一、不可执行、缺乏几何验证。在 OpenCAD 基准上超越 GPT-5.2 及 DeepCAD、SketchGen 等 SOTA。

25VisCAD

2026基础模型套件

方法：多模态工业 CAD 智能基础模型套件，把 CAD 生成表述为"多模态程序生成"——给定语言或视觉证据表达的意图，模型产出 CAD DSL 程序。聚合 BenchCAD、CADBench、P3D-Bench 等基准。

Motivation：CAD 本质是把用户设计意图映射为广义参数化 CAD 程序；现有方法仍是"零件中心"的（一个实体、单一监督来源），需要统一的基础模型视角。

26CAD-Coder

2025CadQueryGRPO

方法：把文本到 CAD 重构为生成 CadQuery Python 脚本。两阶段：SFT 建立基础，再用 GRPO 强化学习，奖励 = 几何奖励（执行代码算 Chamfer Distance）+ 格式奖励（语法合法性与执行成功率）。

Motivation：CadQuery 天然支持高精度参数与丰富操作；但仅 SFT 无法保证几何准确性，对需多步空间推理的复杂模型表现不足。Mean CD 6.54（Text2CAD 为 29.29，降低约 78%），代码无效率仅 1.45%。

27FlexCAD

2025可控生成

方法：通过微调 LLM 实现统一、通用的可控 CAD 生成。

Motivation：现有可控 CAD 生成方法可控性有限（仅覆盖部分构建层级），且不同控制类型需多个模型支持，效率低。

Motivation：① 现有草图数据集只有线/弧/圆等基础图元，重建质量远逊于工业软件；② 缺乏选择机制，无法支持倒角、倒圆、旋转等高级操作。这两点让现有数据集远离真实工业设计流程。

Motivation：把人类专家的 CAD 操作经验转化为可执行模型——不仅预测单步动作，还能处理长时序依赖，生成连贯完整的建模流程。

Motivation 归纳：十条主线

Why the field does what it does
1
可编辑性。mesh 与点云丢失了设计意图与建模历史，改个孔径都得重做；只有参数化序列 / 程序才能保留"可修改"这一 CAD 的灵魂。
2
精确性。制造与仿真需要 NURBS 级别的精确几何，网格太粗糙。这直接催生了 B-Rep 直接合成与代码生成两条路线。
3
拓扑有效性。生成的模型必须无自交、水密、非流形合法，否则无法成为实体。多阶段生成、几何后处理、约束解码都是为此服务。
4
模态鸿沟。图像表达"外观"，CAD 表达"离散操作 + 连续参数"，两者表示差异巨大。多模态对齐与几何条件编码器（深度图、表面法线）是主要应对手段。
5
数据稀缺。真实图像-CAD 配对数据极少，构造历史数据规模普遍小于 10k 且不可执行。合成数据、程序化生成、agentic 合成成为破局方向。
6
监督信号不足。只用序列监督会忽略全局外观，而且渲染是"多对一"的——多个合法序列渲染出同一结果，模型会过度偏向训练集中出现过的那些。视觉反馈 RL 因此被引入。
7
表达能力受限。早期方法只支持草图 + 拉伸，无法表达倒角、倒圆、旋转等工业常用操作。扩展操作词表与实体选择能力（指针机制）是关键突破。
8
效率。代码生成 token 长约 4 倍、推理慢 4.7–6.61 秒；命令序列 token 短、推理快。指针机制试图在保持短序列的同时获得代码的表达力。
9
量化误差。命令序列必须把连续参数离散化到有限词表，2-bit 量化下 0.7cm 只能变成 0.67cm。指针直接吸附 B-Rep 几何元素，从根本上降低量化误差。
10
长程依赖。复杂工业模型的命令序列极长，注意力成本高、易漂移。层次化码树、状态空间模型、计划级监督（先规划再构造）都是应对方案。

趋势与挑战

Where the field is heading

↗四大趋势

① 从外观到设计。从"生成一个看起来像的形状"转向"生成可编辑、可参数化、可约束、可制造的设计"。
② 从单模态到多模态。文本、图像、点云统一到一个框架（CAD-MLLM、VisCAD、cadrille）。
③ 从 SFT 到 SFT + RL。用视觉反馈、几何奖励、代码可执行性做强化学习对齐。
④ 从单模型到 Agent 工具链。LLM 调用 CAD 内核形成"规划—执行—反思"闭环（Zero-to-CAD、text-to-cad）。

⚠六大挑战

① 几何约束与参数化编辑：许多方法只生成最终几何，缺少可求解的内部约束系统。
② 拓扑正确性：非流形拓扑仍易出错，后处理偶尔失败。
③ 设计意图保持：生成结果是否真正理解用户意图。
④ 长序列与复杂操作：真实工业建模历史仍稀缺。
⑤ 评测协议工业化：从形状相似度走向参数级精度（Pointer-CAD v2 已开先河）。
⑥ 多轮交互：真实设计是迭代过程，现有方法多为一次性生成。

工业落地信号： Autodesk 于 2025 年 10 月正式发布 Neural CAD，声称可自动化 80–90% 的常规设计任务，训练数据来自专业 CAD 几何体（互联网上买不到，构成真实数据护城河）； CATIA 2025 推出草图生成式约束功能，用图神经网络自动生成符合行业规范的约束组合； ECCV 2026 设立官方 CAD Challenge，要求参赛方输出标准 STEP 格式 B-Rep，用 OCCT 内核从 Surface / Edge / Vertex / Topology 四个维度评分。 这标志着该方向正从论文走向产线。
一句话总结：CAD 生成的竞争，本质是"表示"的竞争——谁能在效率（短序列）、精度（高保真参数）、表达力（丰富工业操作）三者间找到最优解，谁就能率先跨过工业可用的门槛。

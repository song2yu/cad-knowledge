ABC

2019 CVPR 2019

A Big CAD Model Dataset For Geometric Deep Learning

几何深度学习领域的奠基级 CAD 数据集，每个模型包含显式参数化的曲线与曲面，可采样出不同格式与分辨率的数据，为曲面法线估计、补丁分割、几何特征检测、形状重建提供 ground truth。

B-Rep（STEP）、网格、点云、特征标注

Fusion 360 Gallery

Recap-OmniCAD+

2026 CVPR 2026

Pointer-CAD: Unifying B-Rep and Command Sequences via Pointer-based Edges & Faces Selection

扩展 OmniCAD 基础数据，新增倒角、圆角等工业级操作指令，用多视角渲染 + Qwen2.5-VL 自动生成高质量文本描述。核心创新是指针机制，把几何实体选择与命令序列结合，显著降低量化误差。保留实际参数与单位，不做几何归一化。

数据类型
B-Rep + 命令序列 + 指针标注（Label / Value / Pointer 三类 token）+ 文本描述

关键洞察

Key takeaways

① 数据形态正在从「几何」走向「过程」

早期数据集（ABC、CC3D）只保存最终几何（B-Rep / 网格）；2019 年后 DeepCAD、Fusion 360 Gallery 开始保存 建模历史序列；2025–2026 年的 Zero-to-CAD、Pointer-CAD 则进一步保存可执行、可读、可编辑的程序。 数据集的竞争焦点已经从「有多少模型」转向「模型是否可编辑、可回放、可验证」。

② 规模量级在两年内提升了一个数量级

DeepCAD（2021）17.8 万 → Text2CAD（2024）17 万模型 + 66 万文本 → Brep2Seq（2024）100 万 → Zero-to-CAD（2026）100 万可执行程序 → Pointer-CAD（2026）57.5 万含倒角/倒圆。 同时，合成数据（Brep2Seq、CAD-Recode、Zero-to-CAD）成为突破真实数据稀缺的主要手段。

③ 多模态与工业级操作是当前两条主线

多模态方向：Omni-CAD（文本+图像+点云+序列）、Text2CAD（多层次文本）、VideoCAD（UI 交互视频）。 工业级操作方向：WHUCAD / HPSketch（旋转/圆角/倒角）、Pointer-CAD（实体选择）、OmniCAD-Plan（计划级监督）。 两者共同指向同一个目标——让 AI 生成「真正能用的零件」，而不只是「看起来像的形状」。

④ 评测协议正在工业化

从早期的 Chamfer Distance / IoU 等归一化形状指标，演进到 Pointer-CAD v2 提出的 Vertex / Edge / Face Accuracy + RMR@3 参数级指标，且不做归一化。 ECCV 2026 官方 CAD Challenge 要求输出标准 STEP 格式 B-Rep，用 OCCT 内核从 Surface / Edge / Vertex / Topology 四维评分。

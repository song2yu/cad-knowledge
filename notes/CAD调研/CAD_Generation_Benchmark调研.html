评测指标全景

Metrics taxonomy · 四大类指标
Shape-level

◐ 形状级指标

Chamfer Distance (CD) IoU COV MMD JSD
问题：通常在归一化后计算，对毫米级数值偏差不敏感，会掩盖尺寸误差。

Command-level

◐ 命令级指标

F1（命令 / 参数准确率）SegE（分割误差，衡量拓扑正确性）
用途：衡量生成序列与真值序列的操作级一致性。

Topology validity

◐ 拓扑有效性指标

IR（无效率）SIR（自交率）DangEL（悬边长度）FluxEE（密封质量）valid_ratio
用途：判断生成结果能否成为合法实体，是工业可用的硬门槛。

B-Rep structure

◐ B-Rep 结构指标

Surface F1 Edge F1 Vertex F1 Topology F1
用途：ECCV 2026 CAD Challenge 采用，用 OCCT 内核网格化 + 点云采样 + 匈牙利匹配评分。

★ Parameter-level (2026 新增)

◐ 参数级指标

Vertex Accuracy：预测顶点与 GT 最近点欧氏距离在容差内才算匹配。
Edge Accuracy：不仅端点定位正确，底层几何参数（圆弧圆心与半径、圆法向等）也须在容差内对齐。
Face Accuracy：所有边界边被正确识别，且原始体类型（平面/圆柱/圆锥/球/圆环）与 GT 一致。
RMR@3：错误面不超过 3 个的模型占比，衡量真实 CAD 工作流中的可用性。

关键设定：参数级指标的容差为 GT 包围盒最小边长的千分之一，且所有模型在原始位置与尺度下评测、不做归一化 ——迫使模型真正理解文本指令中的度量尺度。这标志着评测从形状相似度为主，转向参数精度与 B-Rep 结构并重。

DeepCAD Benchmark Protocol

2021 ICCV 2021 命令序列基准

DeepCAD 评测协议（命令准确率 + 参数准确率 + Chamfer Distance + 无效率）

CAD 生成领域事实上的标准评测协议，几乎所有后续工作都在此基准上对比。评测脚本 evaluate_ae_acc.py（命令/参数准确率）与 evaluate_ae_cd.py（CD + 无效率）已成为社区通用工具。

关键洞察

Key takeaways

① 评测正在从「形状像不像」走向「参数准不准」

早期基准用 Chamfer Distance / IoU 等归一化形状指标，对毫米级偏差不敏感——两个尺寸有差异的模型，IoU 可能都高达 0.96。 2026 年 Pointer-CAD v2 提出 Vertex / Edge / Face Accuracy + RMR@3 参数级指标，且明确不做归一化， 容差设为 GT 包围盒最小边长的千分之一。这直接回应了「0.7cm 被四舍五入成 0.67cm 就足以让零件报废」的工业现实。

② 从「自建评测」走向「官方竞赛」

2021 年 DeepCAD 的评测脚本是社区自发复用的；2026 年 ECCV 官方设立 CAD Challenge， 要求输出标准 STEP 格式 B-Rep，用 OCCT 内核从 Surface / Edge / Vertex / Topology 四维评分， 并叠加 valid_ratio 确定排名。竞赛规则极严：每日限提交 3 次、总计不超过 30 次， 任何缺失、OCCT 无法打开、网格化失败或超时的样本均判为无效。这标志着评测从论文附录走向工业验收标准。

③ 多模态与多任务统一评测成为新趋势

UniCAD 整合 DeepCAD、Text2CAD、CAD-Recode 等来源，构建 140 万+ 模型、150 万+ QA 对的统一基准， 覆盖点云→CAD、文本/图像/草图→CAD、CAD 问答等异构任务。P3D-Bench 则聚焦参数化 3D 生成， 用 400 文本 + 400 图像 + 203 装配案例揭示：装配任务最具挑战，模型能恢复全局形状但无法重现精确参数化几何。

④ 通用大模型在 CAD 领域仍有明显短板

VideoCAD VQA 基准显示：GPT-4.1 在平面识别（87%）、孔洞检测（92%）表现不错， 但在对称检测（18.5%）、帧排序（36%）、挤压计数（47%）上明显吃力。 Pointer-CAD 的对比实验也显示，通用 LLM 的 IR（无效率）高达 23.90%–29.75%， 远高于专用方法的 8.67%。这说明 CAD 领域仍需领域强对齐的专用方案。

⑤ 中国团队在工业级评测中表现突出

ECCV 2026 CAD Challenge 榜首为比特无限联合武汉大学团队（96.39 分，击败 27 支全球队伍）； 复旦大学推出 CADExpert（17,299 实例）与 TriView2CAD（首个三视图理解基准）； 武汉大学发布 WHUCAD / HPSketch；港大 Pointer-CAD 以 0.5B 模型超越 7B 基线。

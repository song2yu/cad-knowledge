01任务定义：从「看见」到「拆出特征」

本调研关注的任务是：给定一张工程图纸（栅格/矢量/扫描件），用视觉语言模型（VLM）输出结构化的加工特征清单与工程基本信息。它不同于纯 OCR，也不同于符号检测——核心在于把视觉元素绑定到工程语义对象上。

输入机械零件图 / 装配图（PDF、扫描件、CAD 导出光栅图、SVG 矢量图）
加工特征孔（通孔/盲孔/沉头/同轴）、槽、台阶、倒角、圆角、锥面、螺纹、型腔
基本信息尺寸与公差、GD&T 形位公差、材料与热处理、表面粗糙度、标题栏元数据、技术要求
输出结构化 JSON：特征类型 + 几何参数 + 关联标注 + 证据位置

📌 与相邻任务的区别：符号检测（FloorPlanCAD 类）只输出「这里有个符号」；本任务要求输出「这是一个 Φ12H7 的配合孔，位于右端面，粗糙度 Ra1.6，基准 A」——即特征 + 参数 + 归属关系三者齐备。

02目标输出 Schema（业界共识形态）

综合多篇论文的产出格式，当前主流的结构化输出形如：

{

  "title_block": { "drawing_no": "...", "material": "Cast Iron", "scale": "1:1", "designer": "...", "date": "..." },

  "features": [

    {

      "feature_type": "hole",          // hole / slot / step / chamfer / fillet / thread / pocket

      "subtype": "through_hole",

      "parameters": { "diameter": 12, "tolerance": "H7", "depth": null },

      "annotations": [

        { "kind": "dimension", "value": "Φ12H7", "bbox": [x1,y1,x2,y2] },

        { "kind": "surface_finish", "value": "Ra1.6", "bbox": [...] },

        { "kind": "gdt", "symbol": "position", "value": "Ø0.02", "datum": "A|B|C", "bbox": [...] }

      ],

      "view": "front"

    }

  ],

  "notes": ["锐边去毛刺 0.1mm", "..."]

}

✅ 关键设计：每条信息都带 bbox（证据位置）——这是工程可复核性的前提，也是 DRAGON 等新基准的核心要求。

⚠️ 关键结论：目前没有公开的「2D 图纸 → 加工特征」专用标注数据集。

  • MFCAD / MFCAD++ 是 3D CAD 模型的面级标注，需投影成图像才能用于 2D 任务；
  • A*STAR 的 1,367 张是少见的真实机械图纸标注集，但为团队自建、未公开；
  • 真实机械工程图纸因保密原因极少公开（多篇论文共同确认）；
  • 因此该方向论文普遍自建数据集，跨论文结果难以直接对比——这是本领域最大的方法论障碍。

📌 替代路径：① 用 MFCAD 投影图做特征识别预训练；② 自建标注（推荐 CVAT 工具，A*STAR 即用此）；③ 拓扑感知合成数据（参考 SynthPID 思路）。

05代表论文与实测性能

5.1 VLM 直接做图纸信息提取

  • From Drawings to Decisions（A*STAR + 南洋理工，arXiv:2505.01530 / 2506.17374）：YOLOv11-obb 旋转框定位 + 微调 Donut 解析，1,367 张图纸 9 类标注。Donut 综合 F1 93.5–94%、精确率 89.2%、召回率 99.2%、幻觉率 10.8%；Florence-2 对比 F1 85.0%、幻觉率 21.6%。GD&T 解析 F1 达 96.5%，标题栏精度仅 52.2%。
  • 多阶段混合框架（同团队）：YOLOv11-det 版面切分 + YOLOv11-obb 标注定位 + 双 Donut 解析，出现「剪刀差」——数值类 VLM 综合 F1 0.963（测量值 0.923、GD&T 0.965、粗糙度 1.0，幻觉率 0.067），而文本类 VLM 综合 F1 仅 0.672（标题栏 0.533、幻觉率 0.478）。
  • Drawing-Recode（韩国忠南大学，arXiv:2607.27558）：交叉注意力 + 标注关联损失（AGL）把标注层显式绑定到几何层，MCD 改善 27.8%，无效输出从 20.31% 降至 0.97%。
  • Integration of Deep Learning for Automatic Recognition of 2D Engineering Drawings（Machines 2023）：视图检测 → 标注组检测 → 标注检测 → 字符识别的四阶段管线，覆盖 GD&T 特征控制框、基准、尺寸标注。

5.2 VLM 做加工特征识别（含 3D 上游对照）

  • Evaluating VLMs for Engineering Design（Springer, 2025）：用 MFCAD 数据集评测 GPT-4V 的加工特征识别（15 类特征），并发布 1,000+ 查询的基准测试集；
  • Image2Feature（IJPEM, 2026）：从 3D CAD 模型投影/剖切图像检测倒角、圆角、孔、锥面，射线投射映射回 B-rep 面 + 几何验证规则，15 个测试模型平均 F1 91.3%，后处理识别沉孔、锥沉孔、同轴孔等复合特征；
  • 【上游对照】MFR 深度学习线：FeatureNet（CAD 2018）、BRepNet、Hierarchical CADNet（CAD 2022）、AAGNet、SSGCN——均在 3D B-rep/点云上做特征识别，不处理 2D 图纸，仅作为「加工特征」概念与分类体系的参考来源。

5.3 端到端 VLM 与领域适配

  • Qianfan-OCR（百度千帆，4B）：端到端文档模型，OmniDocBench v1.5 得分 93.12，居端到端模型首位——验证「端到端优于级联」；
  • Qwen3-VL / GLM-4V / 千问3.5-2B 等：工业界已用于 CAD 图纸尺寸标注识别、公差解析、材料属性提取，支持自然语言定向抽取（如「只提取所有形位公差标注」）；
  • SynthPID（2026）：针对 P&ID 公开标注仅 12 张的困境，用真实管线拓扑作种子生成 665 张合成图，边关系检测 mAP 达 63.8%（模板式合成仅约 33%）。

5.4 综述

  • Moreno-García et al.（Artificial Intelligence Review 2024）：工程图纸数字化深度学习综述，指出数据稀缺与类别不平衡两大痛点；
  • Geometric Deep Learning for CAD: A Survey（IEEE Access 2025）：B-Rep/草图理解与生成的基准数据集全景。

06VLM 的真实能力边界

⚠️ 结论先行：当前 VLM 在图纸理解上呈现明显的「数值强、文本弱、符号弱」梯度，尚未达到工业级可靠性，需配合人工复核。

💡 为什么纯 VLM 不够（多篇论文共识）：尺寸线/引出线的对应关系需像素级精度；公差符号细微差异需专门几何特征提取；视图投影关系（长对正、高平齐、宽相等）需规则校验；材料牌号/热处理规范需领域知识库匹配。主流方案 = VLM 理解上下文 + 传统视觉/规则模块保证定位与格式约束。

VLM 典型失败模式

  • 尺寸线交叉/引出线归属错误：一条尺寸线指向多个几何对象时，模型易张冠李戴；
  • 公差符号混淆：圆柱度、同轴度、圆跳动等符号视觉相似，细微差异易误判；
  • 视图投影关系错误：主视图与俯视图的「长对正、高平齐」关系需规则校验，纯 VLM 常出错；
  • 标题栏幻觉：文本类字段幻觉率高达 0.478（A*STAR 实测），易编造不存在的图号/日期；
  • 特征归属缺失：能识别出「Φ12H7」和「孔」，但无法正确绑定「哪个孔配哪个公差」。

核心难点：尺寸-特征关联

这是本任务最关键的挑战——让每个数值知道自己描述的是哪段几何。Drawing-Recode 提出的标注关联损失（AGL）是当前少见的显式解法：用交叉注意力把标注层特征绑定到几何层特征，使无效输出从 20.31% 降至 0.97%。

落地建议

  • 架构：旋转框检测（YOLOv11-obb 类）先切标注贴片 → 微调 VLM 解析为 JSON → 规则引擎后处理降幻觉；
  • 模型选择：Donut 类严格解码模型在结构化输出上显著优于自由生成模型（幻觉率差近一倍）；
  • 评测：必须分层报告「检测 mAP + 字段 F1 + 幻觉率 + 证据定位」，单一指标会严重高估能力；
  • 数据：公开真实机械图纸稀缺，建议自建标注（CVAT）+ 合成数据（拓扑感知生成）双轨并行。

01任务谱系：什么叫「CAD 图纸理解」

CAD 图纸理解（CAD Drawing Understanding）指从 2D 图纸中提取结构化信息的一类任务，与「图纸 → 3D 模型 / 程序」的生成任务相区分。按输出粒度可分为五档：

L1 符号检测/识别定位并分类图纸中的符号（门、窗、阀门、粗糙度符号等），输出框/类别
L2 全景符号定位Symantic + Instance：可数符号（things）+ 不可数区域（stuff）统一分割
L3 参数化基元分析解析点/线/圆/弧基元 + 几何约束 + 尺寸标注层的结构化关系
L4 结构化信息提取提取尺寸/公差(GD&T)/材料/标题栏/BOM 表等工程语义信息，输出 JSON
L5 三视图重建从多视图理解几何并重建 3D（与 CAD 生成交界）

📌 本调研聚焦 L1–L4 的纯理解类任务；L5 因与生成强耦合，仅在对照部分简述（详见知识库「CAD生成」分类笔记）。

03Benchmark 与评测指标

  • 符号定位类：FloorPlanCAD 定义的 Panoptic Quality（PQ）及其变体（SQ×RQ）；语义符号定位用 mF1 / weighted-F1（VectorGraphNET 采用）；检测类用 mAP（建筑检测 YOLO 系列报告 79–83%）。
  • 参数化基元分析类：PHT-CAD 提出按基元类型（点/线/圆/弧）分别回归 + 约束一致性评测，配合 P-MSE 数值损失。
  • 结构化信息提取类：YOLOv11+Donut 框架（arXiv 2505.01530）用 precision / recall / F1 / hallucination rate 衡量 9 类工程语义（GD&T、公差、粗糙度、标题栏等）的提取质量，单模型最优 F1 97.3%。
  • 图纸→3D/程序类（理解×生成交叉）：可执行率、Solid IoU、Surface IoU、视觉语义 Judge 分（visCAD / RealCADBench 协议）。

✅ 选型建议：做符号级理解 → FloorPlanCAD（+PQ 指标）；做工程语义提取 → SIED/自建集 + F1 协议；做参数化理解 → ParaCAD；做理解-生成贯通评测 → RealCADBench 2D Drawing 切片。

04代表论文（按技术路线）

4.1 光栅图像 + 检测/分割路线

  • PanCADNet（Fan et al., ICCV 2021）：FloorPlanCAD 原始基线，Faster R-CNN 识别 things 实例 + GCN 推理 stuff 语义；
  • CADTransformer（Fan et al., CVPR 2022）：全景符号定位 Transformer，端到端向量基元感知；
  • SymPoint / SymPoint-V2（CVPR 2024 / 2025）：把符号定位当作点集分割，V2 引入图层特征增强（LFE）模块显著提速提准；
  • CADSpotting（arXiv 2412.07377, 2024）：密集点采样把 CAD 原语转 3D 点云 + 滑动窗口聚合，攻克大图（LS-CAD）上的尺度与重叠难题；
  • YOLO 系工程检测：Elyan et al.（Neural Networks 2020）符号检测分类；YOLOv11+Donut（2025）做 GD&T/材料/标题栏结构化提取。

4.2 矢量图 + 图网络路线

  • GAT-CADNet（Zheng et al., CVPR 2023）：图注意力网络处理矢量基元关系；
  • VectorGraphNET（TUM, arXiv 2410.01336, 2024）：图注意力分割复杂技术图纸，FloorPlanCAD weighted-F1 达 SOTA，且比视觉方案更可扩展。

4.3 VLM / 序列学习路线（2024–2026 新趋势）

  • PHT-CAD（arXiv 2503.18147, 2025）：VLM + 四个回归头做参数化基元分析，EHP 混合参数化 + 三阶段渐进调优，配套发布 ParaCAD 基准；
  • Drawing2CAD（ACM MM 2025）：把「图纸→参数化 CAD」重构为序列到序列学习，双解码器解耦命令类型与参数生成，发布 CAD-VGDrawing；
  • DeepSeek-OCR-2 等 OCR 大模型（2025–2026）：视觉因果流架构对 CAD 扫描图做尺寸/公差/BOM 结构化提取，成为工业落地的低成本路径；
  • visCAD-M1（arXiv 2609.03811, 2026）：27B 多模态模型统一接收图纸/照片/文本/渲染图，虽以生成为主，但其三视图与 2D Drawing 切片是当前图纸理解能力最系统的横评。

4.4 综述

  • Moreno-García et al.（Artificial Intelligence Review, 2024）：深度学习工程图纸数字化综述——符号识别/文本提取/连接信息三主线，指出数据稀缺与类别不平衡两大痛点；
  • Geometric Deep Learning for CAD: A Survey（IEEE Access, 2025）：覆盖 B-Rep/草图理解与生成的基准数据集全景清单。

06关键挑战与机会

  • 数据瓶颈：真实工程图纸保密性强，公开集以建筑/合成为主；ParaCAD 与 LS-CAD 是稀缺的真实工业尝试；
  • 标注成本：线粒度标注极贵（FloorPlanCAD 投入 11 名标注员 1000+ 人时）；
  • 类别不平衡：SIED 专门指出符号长尾问题；
  • 多模态对齐：几何层与标注层（尺寸/公差文字）的联合理解才刚起步（PHT-CAD 是首个双层基准）；
  • 机会：VLM/OCR 大模型正在降低图纸理解门槛；「理解 × 生成」统一评测（visCAD 路线）与跨 CAD 后端的中间表示（IR）值得持续跟踪。
